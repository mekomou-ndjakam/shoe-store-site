# Aurora Shoe Store

Site vitrine de boutique de chaussures, realise en HTML, CSS et JavaScript vanilla.

## Lancer le projet

Ouvrir `index.html` dans un navigateur, ou utiliser une extension comme Live Server dans VS Code.

## Collaboration Git

Creer une branche pour chaque fonctionnalite ou correction :

```bash
git checkout -b feature/nom-de-la-fonctionnalite
```

Puis enregistrer et partager les changements :

```bash
git add .
git commit -m "Ajouter une fonctionnalite"
git push -u origin feature/nom-de-la-fonctionnalite
```
